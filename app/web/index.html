What is it?

A honeypot is a fake system that has no real users, so anyone who touches it is suspicious by definition. This app runs five of them on your machine and records every login attempt, command and exploit.

Why "adaptive"?

Classic honeypots always answer the same way and skilled attackers spot them quickly. Here, a learning engine profiles each visitor (bot, scanner, script kiddie, skilled) and picks the deception strategy that has kept that kind of attacker busiest so far.

What do you do here?

Watch attacks live on the Dashboard, launch safe simulated attacks in the Attack Lab, configure all nine areas, then export reports and threat intelligence. Every action you take is recorded in History.

1Architecture as a linked list

Every attacker interaction travels through the system as a chain of nodes. Each node holds data (what it does) and a next pointer to the stage that receives its output. Click a node to expand it.

The one back-pointer: when a session ends, node 6 computes a reward and sends it back to node 5. This feedback edge is what makes the system adaptive: the next attacker of the same kind is met with whichever strategy has worked best.

4Get started in 5 steps

  1. Create your account. The first account becomes the admin. Sign up
  2. Acknowledge governance. The dashboard asks the admin to confirm the legal and safety rules once.
  3. Generate traffic. In the Attack Lab, run a single scenario or start a campaign. You can also type into the decoy yourself in the web terminal.
  4. Watch it adapt. On the Dashboard, see profiles, ATT&CK techniques, alerts and the strategy chosen for each attacker.
  5. Export intelligence. Download the analysis report, CSV, STIX bundle or your adaptive activity report from Reports.
Safety by design: decoys never execute anything; wget, curl and ssh inside them are simulated. Sensors bind to 127.0.0.1 by default, outbound calls go only to integrations you configure, and simulated attackers use the reserved range 198.18.0.0/15.
